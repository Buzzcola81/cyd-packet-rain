Prerequisites

  1. Use Chrome or Edge on a Windows computer.
  2. Install the CH340 USB driver if needed.
  3. Connect your CYD board via USB.

Flash Firmware

Your browser does not support Web Serial. Use Chrome or Edge. Web Serial is not allowed in this context.

After Flashing

  1. Connect to WiFi by using the device's setup menu.
  2. Open the board's IP address in a browser to access the web admin. (IP available in the System menu)
  3. Configure OpenWrt (Optional) for VPN management, and OpenWeatherMap settings (Optional).

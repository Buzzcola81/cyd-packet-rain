CYD Packet Rain

ESP32-2432S028 Web Flasher

Your browser does not support Web Serial.
Please use Google Chrome or Microsoft Edge on desktop.

Prerequisites

  1. Use Chrome or Edge on a desktop computer.
  2. Install the CH340 USB driver if needed.
  3. Connect your CYD board via USB.

Flash Firmware

Your browser does not support Web Serial. Use Chrome or Edge. Web Serial is not allowed in this context.

This will flash the latest release firmware to your board. After flashing, connect to the board's web admin on port 80 to configure WiFi and other settings.

After Flashing

  1. The board will create a WiFi access point or connect to your configured network.
  2. Open the board's IP address in a browser to access the web admin.
  3. Configure WiFi, OpenWrt, and OpenWeatherMap settings.
